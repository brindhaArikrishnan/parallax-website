# 🌸 Bloomora – Flower Boutique Website

A modern and elegant flower boutique website designed to make flower shopping beautiful and simple.

## 🌷 Live Demo
https://5b4130775d51-0af40120-8080.ws6.app/

## ✨ Features
- 🏠 Beautiful Home Page
- 🌹 Flower Collection
- 💐 Bouquet Collection
- 🎉 Occasion-Based Flowers
- 🎥 Video Background Sections
- 🛒 Add to Cart Functionality
- 💳 Checkout Page
- ✅ Order Confirmation Page
- 🎨 Premium Floral Design
- 📱 Responsive User Interface
- ✨ Smooth Animations and Visual Effects

## 💻 Technologies Used
- HTML
- CSS
- JavaScript

## 🎯 Project Goal
To create an attractive and user-friendly online flower shopping experience where users can explore flowers, select bouquets, add products to their cart, and proceed through the checkout flow.

## 🌱 Learning Outcome
This project helped me improve my skills in frontend development, responsive web design, CSS animations, multi-page navigation, and JavaScript-based cart functionality.
